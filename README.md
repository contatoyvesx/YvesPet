# YvesPet

Loja virtual pet com identidade premium em creme, bege, caramelo e marrom.

## Requisitos
- Node.js 20.9 ou superior
- npm

## Executar localmente
```bash
npm install
npm run dev
```
Abra http://localhost:3000.

## Observações
A primeira versão é uma vitrine visual. Os produtos, preços e parcelamentos são dados demonstrativos, sem estoque, pagamento ou integração com fornecedores. Não publicar como loja transacional até conectar produtos reais, frete, políticas comerciais e checkout.
